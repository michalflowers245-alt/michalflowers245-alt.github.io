# 共创活动筹备示例

测试输入 v1 · 本地公开示例 · 用于验证标题、段落、列表与表格的保留

筹备一场共创活动时，需要把散落在不同资料中的目标、分工与交付要求整理到同一处。本示例讨论如何把一份活动准备说明，转成可保存、复核和交接的资料条目。它不是活动报名页，也不代表活动已经举办。

## 一、先明确本次共创要解决的问题

假设讨论主题是“如何整理团队的公开学习材料”。组织者先收集问题，再让参与者选择一个具体任务：确认来源、整理要点，或者形成一份可以交接的说明。材料需要保留原始标题与出处，避免脱离上下文后无法复核。

## 二、把准备动作拆成可交接的步骤

1. 收集公开材料：记录标题、来源链接与适用主题。
2. 整理讨论问题：把模糊需求改写成可以回答的小问题。
3. 确认角色分工：区分主持、资料整理和结果记录。
4. 会后形成交付：导出一份包含来源的 Markdown 记录。

## 四、这份样例要验证什么

验证快摘能否从同一网页采集正文，保留标题、层级、列表及表格，再保存到本地资料库并导出实际 Markdown 文件。任何成功的演示都只能证明本次软件路径可运行，不能推导真实用户增长、收费、活动效果或团队业务成绩。
