01

项目与问题

同一教学问题，三种交付阶段

这组 2026 年的实践针对教师备课、课前测、反馈和复习中资料分散、重复录入的问题，梳理从资料到题目、从作答到可核对反馈的工具流程。

物理工作台已有本机运行与验收记录；真题和学生题单引擎已有整理、核验与导出流程；AI 教育平台 Agent 是平台层的系统技术设计，三者处于不同交付阶段。

02

本人角色

我的工作与教学判断边界

我负责教学需求拆解、产品与数据流程设计，通过 AI 工具协作推进实现。核心是把重复整理与教学判断分开：AI 识别作为候选，成绩、标准答案、模糊题目与家长反馈由教师核对确认，原件和历史保留以便回查。

03

目标与关键判断

重复整理交给工具，教学判断留给教师

三项工具共同围绕一个目标展开：保留原题和来源，减少重复整理，让教师能够核对从作答、题单到反馈的每一步。

物理工作台承接一次课的记录与反馈，真题题单服务检索与导出，教育 Agent 则是平台层设计。三者不混写成同一套已经上线的系统；成绩、答案和模糊识别结果仍由教师确认。

04

推进流程

真题与题单：从找题到学生版

按年级、章节和知识点找题，查看原题图与来源后加入草稿；教师审核答案、分值、题目和题图完整性，确认后下载或打印学生版。

学生版使用原题裁图，不混入重复 OCR 文字、答案或内部字段。导出前后核对审核状态与版本，题目修改或撤销确认后不能继续交付旧卷。

物理工作台：一次课怎样闭环

本机工具处理班级与课次隔离、稳定学生标识、双窗口写入冲突，以及数据库和原件备份恢复。9 月 13 日优化将两个 PDF 上传入口和五步进度放到首页，让教师更容易找到下一步。

  1. 上传标准答案与学生试卷，检查页码和学生对应关系，再进行录分与逐题校对。
  2. AI 识别先进入候选区；教师采用、修改和确认后形成正式记录，不直接覆盖已有成绩。
  3. 根据成绩与错因形成反馈草稿，保留教师手写内容；复制反馈与实际发送分别标记，发送仍由教师完成。
  4. 进入订正与复习，记录后续进步，同时保留原始考试成绩和历史版本。

05

核心产品或机制

AI 教育 Agent：平台层的设计

Agent 方案连接课程资料、课堂问答、出题、辅助批改和学情：先检查课程权限，再检索并生成带来源的结果，高风险输出由教师审核。

27 页技术设计覆盖课程知识库、混合检索、结构化输出、可回放记录、接口及两期交付范围。响应时间、并发量和准确率均为设计目标，不是本机工具的实测结果。

06

代表案例与材料

从误切修复到完整题单样张

从原题到可核对的学生版

  1. 找到原题按知识点选择题目，保留原题裁图、原题号与页码，随时核对来源。
  2. 教师确认审核题目、题图、答案和分值；修改或撤销确认后，旧卷不能继续交付。
  3. 导出题单学生版只呈现已核对的题目，导出前检查完整性与确认版本。

我负责需求与数据流程；教学判断和正式交付仍由教师确认。

9 月 13 日题单验收发现部分小数被识别成题号，导致误切。修复时保留历史、停用误切内容并恢复原题，没有覆盖全部资料或自动赋予教师确认。

整理后有 900 道有效题、1,136 个原题区域，来源身份与哈希逐一检查零失败。它验证来源、裁图与记录的一致性，答案和教学正确性仍需教师逐题核验。

关键实现JavaScript

只把学生需要的字段交给题单

教师核对题目后，学生版需要保留题面与必要题图，但不能把答案、解析和内部备注一起导出。

实现作用：把教师资料与学生输出分开。上方两页题单样张展示最终输出，这段实现说明输出数据如何被限制。

  /** Return an explicit allow-list DTO. Do not add convenience spreads here. */
  function studentQuestionDTO(question, { imageAssets = safeImageAssets(question) } = {}) {
    const check = readiness(question, { imageAssets });
    if (!check.ready) throw new Error(check.issues.join("；"));
    const dto = {
      questionNo: str(question.questionNo),
      score: Number(question.score),
      stem: str(question.stem),
      options: normalizeOptions(question.options),
      tables: normalizeTables(question),
      imageAssets: imageAssets.map((asset, index) => ({ assetId: str(asset.assetId || asset.id), alt: str(asset.alt) || `题目必要图示 ${index + 1}` })),
    };
    if (contentMode(question, { imageAssets }) === "original") dto.contentMode = "original";
    return dto;
  }

摘录为完整函数；审核规则、图片服务与 PDF 排版位于其他模块。这里展示字段约束，不代表所有题目已经审核或教学效果已经验证。
